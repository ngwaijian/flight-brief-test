Interface & Functions

Load
Upload Flight Plan (OFP)

Click the blue Load button to select your PDF Flight Plan. The app parses Sectors, Fuel, Weights, and EDTO data automatically.

Smart Navigation

Timeline Jump: Tap any row in the Mission Timeline to instantly scroll to that sector's details.
Back to Top: Use the floating arrow (bottom-right) to return to the summary quickly.

Settings / Database

Manage your Aircraft Weight Database. You can manually upload a new PDF database or sync with the cloud (if available).

View Original PDF

Opens the currently loaded PDF file in a new browser tab for cross-checking data or reading non-parsed sections.

Export PDF

Generates a high-quality PDF of the currently visualized flight sectors, perfect for digital record keeping.

Flight History

Quickly access your recently loaded flight plans. Tap any entry to reload the data immediately.

RTD
Real Departure Time (RTD)

Enter your actual Off-Block Time in the yellow box. The app will automatically recalculate your Arrival Time (RTA), Alternate ETA, and all EDTO Entry/Exit windows.

FDP Calculator

A standalone tool to calculate allowable Flight Duty Periods, Standby limits, and Rest requirements based on acclimatization and sector counts.

Delay Code Finder

Searchable database of IATA/Airline delay codes. Filter by category (PAX, TECH, OPS, WX, RAMP) to find the correct code quickly.
